# 🌪️ US Natural Disasters Analysis (FEMA Data)

## 📌 Project Overview
This project analyzes **US Natural Disaster data from FEMA** to understand disaster trends, impacts, and patterns across different states and time periods.The goal is to generate meaningful insights using dashboards and KPIs that can support better disaster preparedness and decision-making.

---

## 🧩 Problem Statement
Natural disasters occur frequently in the United States and cause major damage to people, property, and infrastructure.  
This project aims to answer questions like:

- Which states face the most disasters?
- What types of disasters occur the most?
- How have disasters changed over the years?
- What is the overall impact and severity?

---

## 📂 Dataset Description
The dataset is collected from **FEMA (Federal Emergency Management Agency)** and contains records related to disaster declarations across the United States.

### Dataset includes:
- Disaster type (flood, hurricane, wildfire, etc.)
- State and location details
- Disaster declaration dates
- Incident duration
- Disaster category and severity indicators

> 📌 Source: FEMA Open Data / FEMA Disaster Declarations dataset

---

## 📊 KPI (Key Performance Indicators)
KPIs are **quick measurements** that summarize the performance or trend of the dataset.

### Key KPIs used in this project:
- **Total Disasters Count**
- **Disasters by State**
- **Disasters by Type**
- **Year-wise Disaster Trend**
- **Most Affected Regions**
- **Top Disaster Categories**

---

## 🔍 Key Insights
Some important insights discovered from the analysis include:

- Certain states experience disasters more frequently than others.
- A few disaster types dominate the dataset (like floods/storms).
- Disaster declarations have increased in some recent years.
- Some regions show repeated patterns of similar disasters.
